# 🎥 LifeSpot — Прямые трансляции с улиц

**LifeSpot** — это веб-сервис для просмотра прямых трансляций с уличных веб-камер по всему миру в режиме реального времени. Проект выполнен и доработан в рамках учебного курса SkillFactory ([за основу был взят оригинальный проект](https://github.com/SkillFactory-CSARP/LifeSpot)).

> [!NOTE]
> Итоговый проект по модулю 31.4 курса SkillFactory: Домашнее задание по C# - LifeSpot (HW-03)

---

## 🆕 Последние обновления

В свежем обновлении проведен глубокий рефакторинг архитектуры проекта, внедрены современные практики отладки и добавлен новый интерактивный UI-компонент:

### 1. Архитектурный рефакторинг Backend (`Startup.cs` и `EndpointMapper.cs`)
* **Соблюдение принципа единства ответственности (SRP):** Класс `Startup.cs` очищен от низкоуровневой логики маршрутизации.
* **Методы-расширения (Extension Methods):** Создан статический класс `EndpointMapper.cs`, содержащий модульные методы-расширения (`MapHtml`, `MapCss`, `MapJs`, `MapImages` и единый метод `MapLifeSpotEndpoints()`).

### 2. Интерактивный фото-слайдер («О проекте»)
* **Многофункциональное управление:** Реализована возможность переключения слайдов как с помощью кнопок навигации (`❮` и `❯`), так и при помощи прямого перетаскивания мышью (**Drag & Drop / Swipe**).
* **Событийная модель:** Подключены обработчики событий мыши (`mousedown`, `mousemove`, `mouseup`, `mouseleave`) с плавными CSS-трансформациями (`transform: translateX`).
* **Динамическая раздача изображений:** Добавлен параметризованный C# эндпоинт `/Static/Images/{fileName}` для обработки медиа-ресурсов.

### 3. Современная отладка JavaScript (Замена `alert`)
* Устаревшие и блокирующие UI окна `alert()` полностью заменены на профессиональные инструменты разработчика.
* Внедрен вывод структурированных логов (`console.log`), предупреждений валидации (`console.warn`) и ошибок (`console.error`).
* Добавлена точка останова `debugger;` для пошаговой инспекции DOM-дерева и переменных при добавлении отзывов.

## 🛠 Полный список возможностей и доработок

### 1. Контент и разметка (HTML5)
* **Заголовок:** Главный слоган проекта `<h1>LifeSpot — прямые трансляции с улиц</h1>`.
* **Встраивание трансляций:** Прямые эфиры из Санкт-Петербурга, Нью-Йорка и Лондона через теги `<iframe>`.
* **Карточки видео:** Каждая трансляция снабжена подзаголовком и описанием.
* **Боковое меню (`aside` & `navbar`):** Удобная навигация между страницами «Все трансляции» (`/`) и «О проекте» (`/about`).
* **Поисковая строка:** Текстовое поле поиска с анимацией фокуса.
* **Информационный блок:** Предупреждение о возможной недоступности плееров YouTube на территории РФ.
* **Фиксированный подвал:** Подвал с контактами и копирайтом.

### 2. Стилизация (CSS3)
* **Внешний файл:** Все стили вынесены в `Static/CSS/index.css`.
* **Плиточная верстка (Flexbox):** Адаптивная сетка карточек видео (`display: flex; flex-wrap: wrap;`).
* **Галерея и слайдер:** Кастомные стили для трека слайдера, эффекты наведения на кнопки, управление курсорами (`grab` / `grabbing`).
* **Интерактивность:** Плавная подсветка ссылок меню (`:hover`), фокус на поле ввода (`:focus`), оформление блока отзывов.
* **Фиксация футера:** Защитный отступ `padding-bottom` для `body`, предотвращающий наложение контента на подвал.

### 3. Клиентская логика (JavaScript ES6+)
* Динамическое управление слайдером и свайпом мышью.
* Валидация пользовательского ввода и интерактивная публикация отзывов без перезагрузки страницы.
* Динамическая работа с DOM (`document.createElement`, `.appendChild()`).
* Использование классических (`function`) и стрелочных функций (`const fn = () => {}`).

### 4. Серверная часть (ASP.NET Core / C#)
* Модульная маршрутизация эндпоинтов в `EndpointMapper.cs`.
* Отдача статических файлов (HTML, CSS, JS, Images) через асинхронное чтение и потоковую передачу данных.
