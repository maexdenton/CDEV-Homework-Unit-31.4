# 🎥 LifeSpot — Прямые трансляции с улиц

**LifeSpot** — это веб-сервис для просмотра прямых трансляций с уличных веб-камер по всему миру в режиме реального времени. Проект выполнен и доработан в рамках учебного курса SkillFactory ([за основу был взят оригинальный проект](https://github.com/SkillFactory-CSARP/LifeSpot)).

> [!NOTE]
> Итоговый проект по модулю 29.7 курса SkillFactory: Домашнее задание по C# - LifeSpot (HW-03)

---

## 🆕 Последние обновления

В текущей версии реализован интерактивный функционал работы с пользователями и многостраничная структура сервиса:

* **Отдельная страница «О проекте» (`/about`):**
  * Создана полнофункциональная страница с информацией о сервисе, сохраняющая общую стилистику сайта (хедер, сайдбар, примечание, футер).
  * В `Startup.cs` настроена маршрутизация для нового эндпоинта `/about`.

* **Интерактивный раздел «Отзывы» (JavaScript):**
  * Создан и подключен внешний файл скриптов `Static/JS/about.js` (с соответствующим эндпоинтом в C#).
  * Реализована классическая функция `getReview()` для запроса имени пользователя и текста комментария через интерактивные диалоговые окна с валидацией ввода.
  * Реализована стрелочная функция `addReview()`, которая динамически формирует HTML-карточку отзыва и встраивает ее в DOM-дерево страницы с автоматической генерацией даты и времени публикации.
  * Добавлены стили для оформления карточек отзывов и кнопки интерактивного ввода.

## 🛠 Полный список возможностей и доработок

### 1. Контент и разметка (HTML5)
* **Заголовок:** Главный слоган проекта `<h1>LifeSpot — прямые трансляции с улиц</h1>`.
* **Встраивание трансляций:** Прямые эфиры из Санкт-Петербурга, Нью-Йоркa и Лондона через теги `<iframe>`.
* **Карточки видео:** Каждая трансляция снабжена подзаголовком и описанием.
* **Боковое меню (`aside` & `navbar`):** Удобная навигация между страницами «Все трансляции» (`/`) и «О проекте» (`/about`).
* **Поисковая строка:** Текстовое поле поиска с анимацией фокуса.
* **Информационный блок:** Предупреждение о возможной недоступности плееров YouTube на территории РФ.
* **Фиксированный подвал:** Подвал с контактами и копирайтом.

### 2. Стилизация (CSS3)
* **Внешний файл:** Все стили вынесены в `Static/CSS/index.css`.
* **Плиточная верстка (Flexbox):** Адаптивная сетка карточек видео (`display: flex; flex-wrap: wrap;`).
* **Интерактивность:** Плавная подсветка ссылок меню (`:hover`), фокус на поле ввода (`:focus`), оформление блока отзывов.
* **Фиксация футера:** Защитный отступ `padding-bottom` для `body`, предотвращающий наложение контента на подвал.

### 3. Клиентская логика (JavaScript ES6+)
* Валидация пользовательского ввода (`prompt`, `.trim()`).
* Динамическая работа с DOM (`document.createElement`, `.appendChild()`).
* Использование как классических (`function`), так и стрелочных функций (`const fn = () => {}`).

### 4. Серверная часть (ASP.NET Core / C#)
* Маршрутизация эндпоинтов в `Startup.cs` (`/`, `/about`, `/Static/CSS/index.css`, `/Static/JS/about.js`).
* Отдача статических файлов и HTML-страниц через асинхронное чтение файлов (`File.ReadAllTextAsync`).
