# 🎥 LifeSpot — Прямые трансляции с улиц

**LifeSpot** — это веб-сервис для просмотра прямых трансляций с уличных веб-камер по всему миру в режиме реального времени. Проект выполнен и доработан в рамках учебного курса SkillFactory.

> [!NOTE]
> Итоговый проект по модулю 27.9 курса SkillFactory: Домашнее задание по C# - LifeSpot (HW-03)

---

## 🛠 Выполненные доработки и улучшения

### 1. Контент и разметка (HTML5)
* **Новый заголовок:** Старое приветствие заменено на главный слоган проекта `<h1>LifeSpot — прямые трансляции с улиц</h1>`.
* **Встраивание трансляций:** Интегрированы элементы `<iframe>` с прямыми видеотрансляциями из Санкт-Петербурга, Нью-Йорка и Лондона.
* **Описание видео:** Каждая трансляция оформлена в виде отдельной карточки с заголовком и текстовым описанием локации.
* **Боковое меню (`aside` & `navbar`):** Реализована боковая панель навигации со ссылками «Все трансляции» и «О проекте».
* **Интерактивный поиск:** Добавлено текстовое поле поиска трансляций с подсказкой и эффектами фокуса.
* **Информационное примечание:** Добавлен предупреждающий блок о возможной недоступности плееров YouTube на территории РФ.
* **Фиксированный подвал:** Реализован `<footer>` с контактами для обратной связи и информацией о копирайте.

### 2. Стилизация и адаптивность (CSS3)
* **Внешний файл стилей:** Все CSS-правила вынесены в отдельный файл `Static/CSS/index.css`.
* **Плиточная верстка (Flexbox):** Карточки с видео переведены из вертикального списка в современную адаптивную сетку-плитку (`display: flex; flex-wrap: wrap;`).
* **Единый шрифт:** Использован комбинированный селектор для настройки шрифта `"Helvetica 65 Medium", sans-serif` на всем сайте.
* **Приоритетность селекторов:** Продемонстрирована работа со специфичностью CSS за счет использования селектора по идентификатору `#header-index`.
* **Интерактивные эффекты:** 
  * Плавная подсветка и неоновое свечение ссылок бокового меню при наведении (`:hover`).
  * Синяя подсветка и мягкая тень поисковой строки при выборе поля (`:focus`).
* **Исправление верстки:** Настроен защитный отступ `padding-bottom` для `body`, предотвращающий наложение футера на нижние карточки видео.

### 3. Серверная часть (ASP.NET Core / C#)
* **Маршрутизация статики:** В `Startup.cs` добавлен эндпоинт `/Static/CSS/index.css` для корректной отдачи внешних CSS-файлов сервером браузеру.
